Платформер на Python
Игра-платформер, разработанная на языке Python с использованием библиотеки Pygame.

Основные возможности:

Управление персонажем с поддержкой анимации и физики прыжков.

Загрузка уровней из файлов конфигурации в формате JSON.

Интерактивные элементы: сбор монет, зоны с лавой и финишные переходы.

Игровой интерфейс: главное меню, система подсчета очков, ограничение по количеству жизней и звуковое сопровождение.
